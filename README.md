# Sales_Prediction
##Project Overview
Sales prediction helps businesses forecast product demand and optimize advertising strategies.  
This project uses the Advertising dataset to predict sales based on advertising expenditure across TV, Radio, and Newspaper channels.  

We apply data preprocessing, exploratory data analysis (EDA), regression models, and evaluation metrics to build a reliable predictor.

##Dataset
File: `advertising.csv`
Features:
`TV` → Advertising spend on TV
`Radio` → Advertising spend on Radio
`Newspaper` → Advertising spend on Newspaper
Target:
`Sales` → Product sales (in thousands of units)
